# 「幸せのカタチ」本読みアシスタント

演劇「幸せのカタチ」の本読み・稽古用 Web アプリです。

- アプリ: https://kesnonkw.github.io/happy-shape/
- 操作マニュアル: https://kesnonkw.github.io/happy-shape/manual.pdf

## 効果音のクレジット

使用した音素材：OtoLogic（https://otologic.jp）、Gravity Sound — いずれも [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja)

| ファイル | 元素材 | 作者 |
|---|---|---|
| `sfx/chime.wav` | Japanese_School_Bell02-03(Slow-Short) | [OtoLogic](https://otologic.jp) |
| `sfx/door-open.wav` | open closet door | Gravity Sound |
| `sfx/door-close.wav` | close door | Gravity Sound |
| `sfx/line.wav` | Notification | Gravity Sound |
| `sfx/notification.wav` | Notification 2 | Gravity Sound |

上記はアプリでの再生用に加工しています（WAV 変換、低音カット・中高音強調、音量の最大化、フェード）。`sfx/ringtone.wav` はオリジナルの合成音源です。
各素材の出典 URL など詳細は [`sfx/CREDITS.txt`](sfx/CREDITS.txt) を参照してください。

本アプリは各素材の権利者から個別の協力・支持・認証を受けたものではありません。音源ファイルを再利用・再配布する場合は、クレジット表記を引き継いでください。
